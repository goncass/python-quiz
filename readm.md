# Quiz em Python

Um jogo de quiz interativo no terminal, com perguntas de cultura geral.

## Como correr

1. Instala o Python 3
2. Corre: `python quiz.py`

## O que aprendi

- input/output
- condicionais (if/else)
- loops (se aplicável)
- f-strings para formatação

## Funcionalidades

- 6 perguntas de dificuldade variável
- pontuação ponderada (1-3 pontos por pergunta)
- percentagem final
